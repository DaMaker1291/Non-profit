## The question this review answers

Not "is the interface pleasant". **Would you use this to teach the concept, and what would you change before using it with your pupils?** Correct the subject accuracy first; then the level, the wording, and the model's simplifications.

## 1. What the learner is meant to be able to do

Decide which element an atom is from its particle counts, and say what a neutron or an electron changes instead.

> **The lesson plan behind this concept is the generated supplemental fallback, not an authored sequence.** The objective and the prediction above come from the model's own teaching frame; the sequence in section 6 is composed from the concept note, so treat its order and wording as unreviewed structure rather than as an authored lesson.

**The prediction the learner must commit to before touching the model:** One carbon-12 atom gains a neutron; another carbon-12 atom gains a proton. Describe what each atom becomes.

**Describe prediction — nothing is marked.** Prompt: A sentence for each: the element it is now, and whether its mass, its charge or its identity changed.

**Ideas the learner can check their own sentence against:**

- that the atom which gained a neutron is still carbon
- that the atom which gained a proton is a different element
- which count decides the name and which one only changes the mass

**What the reveal says once the description is committed:** The model shows the first still named carbon, with its mass number one higher — carbon-13, an isotope of carbon. The second is nitrogen: the proton count changed, so the element changed with it. A neutron changes the mass, a proton changes the identity, and an electron changes only the charge.

**What the learner does with it afterwards:** Change one particle count and name the element, the isotope and the charge before you check.

**Starting point the lesson assumes:** Gold, oxygen and carbon are different because their atoms have different numbers of protons. The periodic table is organised around that one fact. That count is the atomic number.

## 3. Design decision

Identity first, then the modifiers. The learner changes protons, neutrons and electrons and the model prints ONE sentence whose order is the lesson: the proton count names the element, neutrons only make a heavier version of it, electrons only make it charged. Zero protons is not 'hydrogen gone wrong' — it is not an element, and the model says so.


### Misconceptions the lesson is built to refute

- **mass-decides-element** — Two atoms with different masses must be different elements. _(arc-vic-atomic-structure)_
- **neutrons-equal-protons** — An atom has as many neutrons as protons. _(schmidt-2003-isotopes)_
- **ion-is-different-element** — An ion is a different element from the atom it came from. _(rsc-atoms-isotopes-14-16)_
- **protons-only-sometimes-decide** — The proton count only sometimes decides which element an atom is. _(canterbury-2015-atomic-structure)_
- **atom-equals-element-word** — 'Atom', 'element' and 'matter' are interchangeable words. _(acs-2006-nuclear-misconceptions)_

## 4. The model: assumptions and limits

**Intended level:** 14–16 (atomic structure, isotopes and ions)

**Assumptions (scientific/mathematical):**

- Only the first twenty elements are named; beyond calcium the model says there is no name rather than inventing one.
- Mass number is protons + neutrons, ignoring binding energy and isotopic mass defect.
- Charge is protons − electrons in units of +e.
- The atom is shown as a nucleus plus shells, not as an orbital model.
- An isotope is any atom of the same element with a different neutron count, including unstable ones.

**What it cannot show:**

- No electron configuration rules, subshells or ionisation energies.
- No relative atomic mass or isotopic abundance, so the periodic-table mass is not explained.
- No radioactivity or nuclear decay.
- The shell drawing is a model of the atom, not a scale picture of one.

**Misconceptions it addresses:**

- A different number of neutrons makes a different element.
- An ion is a different element.
- An atom normally has equal protons and neutrons.
- Atom, element and matter are interchangeable words.

**Misconceptions it might accidentally introduce — please check these first:**

- That the shell diagram is what an atom 'looks like'.
- That all isotopes are stable, because nothing on screen decays.
- That mass number is the same as relative atomic mass.

## 6. The teaching sequence

_This plan has no authored sections; the page groups its idea paragraphs. Treat the sequence as unreviewed structure._

An element is one type of atom, listed in the periodic table — 118 known. Atoms: protons (+, in nucleus), neutrons (0), electrons (−, in shells). Atomic number = protons = the element's identity. Chemical reactions rearrange atoms but never change them — matter is conserved.

This idea is the step before Compounds & mixtures, The periodic table, Electron configuration. Keep its definition and its check beside you when those topics use it.

Read an element's symbol and atomic number, then count protons, neutrons and electrons. In a neutral atom, electrons equal protons; an ion has gained or lost electrons.

The atomic number must match the element's position in the periodic table, and the mass number must be a whole number of nucleons. A chemical reaction rearranges atoms but does not change one element into another.

## 7. Questions to ask and traps to expect

- **Thinks a chemical reaction can turn lead into gold by rearranging atoms.** Chemical reactions rearrange atoms into new compounds; they do not change an atom's proton count. Turning lead into gold requires a nuclear reaction, not a chemical one.
- **Balances an equation by changing a subscript instead of a coefficient.** Changing a subscript changes the substance itself: H₂O is water, H₂O₂ is hydrogen peroxide. Balance by placing coefficients in front of the formulas, never by editing the formulas.
- **Confuses the amount of a substance with its concentration or its strength.** Amount, concentration and strength are different axes. Say which one the question asks about, and convert with moles = mass ÷ Mr or concentration = moles ÷ volume rather than guessing.

## 8. Teacher run-of-show

### Before anyone touches the model

1. Write the proton count for hydrogen, carbon and calcium and ask what changes when the neutron count changes. Then add a proton in the model and let the class watch the name change.
1. Contrast this with an electron change: same element, now charged.

### Questions to ask while it runs

- Which count decides the element, and which two counts do not?
- An ion of sodium and an atom of sodium: same element? Same charge? Same mass number?

### One guided activity

Pairs are given six sets of particle counts and must name the element, the isotope and the charge, then check each against the model.

### With no device

A table of particle counts to complete with element name, isotope label and charge, plus a blank shell diagram to label.

### What to look for

A learner who says 'a neutron makes a new element' holds the target misconception. Ask them to name the element after adding a neutron and then after adding a proton: the two answers must differ.

### Where to go next

- Electron shells and the periodic table.
- Relative atomic mass and isotopic abundance.
