### 5. Index laws `indices-intro`

Stage 1 · foundation + higher tier · concept ceiling 0.84 · prereqs `order-ops`

*What it teaches:* a³ means a × a × a. Multiplying powers with the same base adds the indices: a² × a³ = a⁵. Dividing subtracts them: a⁵ ÷ a² = a³. A power of zero gives 1 (a⁰ = 1) because dividing aⁿ by aⁿ must give 1. Negative indices flip into a fraction: a⁻² = 1/a². Fractional indices are roots: a^(1/2) = √a.

**Misconceptions this concept is meant to probe:**

- Misreads negative indices (`neg-exp`) — Treats a⁻² as a negative number instead of 1/a².

**1. Work out (4^2)².**

A. 64
B. 257
C. 32
**D. 256** ✓ key

- Explanation given: A power raised to another power MULTIPLIES the indices, because the factors are themselves repeated: (4^2)² means 4^2 written twice, which is 2 + 2 = 4 factors of 4. So the value is 4^4 = 256. Adding the indices instead (4^4 = 256) is the rule for multiplying powers, not for raising one to a power, and doubling the value of 4^2 (32) is not a power at all.
- Difficulty as served: 0.50 (tier target 0.45) · answered by typing a number
- Reproduce it: `pilot:indices-intro:foundation:0` at the foundation target

**2. Work out (3^3)².**

**A. 729** ✓ key
B. 243

### 9. Completing the square `completing-square`

Stage 3 · higher tier · concept ceiling 0.93 · prereqs `quadratics`

*What it teaches:* x² + 6x + 5 = (x + 3)² − 4: halve the x coefficient, square it, adjust. This form exposes the vertex (−3, −4) instantly, shows the minimum/maximum value, and solves equations by isolating a perfect square. It is also how the quadratic formula is derived — completing the square on the general equation.

**Misconceptions this concept is meant to probe:**

- Completing the square: forgets the constant (`b-half`) — x² + 6x + 5 becomes (x + 3)² without subtracting the added 9.

**1. Express x² + 10x + 21 in the form (x + p)² + q, and hence state the minimum value of the expression and the value of x at which it occurs.**

A. Minimum 4 when x = -5
B. Minimum -4 when x = 5
C. Minimum 21 when x = -5
**D. Minimum -4 when x = -5** ✓ key

- Explanation given: Half the coefficient of x is 5, so the square is (x + 5)² = x² + 10x + 25; the expression has 21 there instead, so it is (x + 5)² − 4 = (x + 5)² − 4. A square is never negative, so the SMALLEST the expression gets is when (x + 5)² = 0 — that is x = -5, and the minimum value is -4. The sign of p is the slip: it is −h in the bracket, so the minimum sits at the opposite sign, -5.
- Difficulty as served: 0.65 (tier target 0.65)

### 11. Surds `surds`

Stage 3 · foundation + higher tier · concept ceiling 0.93 · prereqs `indices-intro`

*What it teaches:* √2 cannot be written exactly as a fraction — its decimal never repeats. A surd is an exact root like √2, √3, √5. Simplify using √(ab) = √a × √b: √50 = √25 × √2 = 5√2. Rationalise denominators by multiplying top and bottom by the surd (or its conjugate for expressions like 1/(1+√2)). Surds keep answers exact where decimals only approximate.
